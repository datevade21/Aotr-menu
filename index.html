Đang kiểm tra...

Trang này chạy độc lập trên website/GitHub của bạn nên cần một cơ sở dữ liệu thật để lưu dữ liệu dùng chung (vật phẩm, khu) giữa mọi người truy cập — mình đã nối sẵn code cho Firebase Firestore (miễn phí).

1. Vào console.firebase.google.com → Tạo dự án mới (miễn phí).
2. Vào Build → Firestore Database → Create database → chọn chế độ test mode.
3. Vào ⚙️ Project settings → General → mục "Your apps" → bấm biểu tượng </> để tạo Web App.
4. Firebase sẽ đưa cho bạn 6 giá trị (apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId).
5. Mở file HTML này bằng trình soạn thảo code, tìm dòng chữ const firebaseConfig gần đầu thẻ <script>, dán 6 giá trị vào đúng chỗ, lưu file và tải lại lên GitHub.
